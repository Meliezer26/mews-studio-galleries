Notifications e-mail

En complément de l'e-mail envoyé par le client : le serveur vous notifie automatiquement avec le détail des albums.
Le mode par défaut : Resend envoie par API HTTPS, sans aucun port SMTP (indispensable sur Render, dont le plan gratuit bloque les ports SMTP). Gratuit jusqu'à 3 000 e-mails/mois. Créez votre compte sur resend.com → « API Keys » → « Create API Key ». Laissez vide pour conserver la clé actuelle. Si une clé est active, le bloc SMTP ci-dessous est ignoré.
Les e-mails partent du compte Google d'envoi choisi ci-dessous (ex. « Mews Studio <mewstudiofrance@gmail.com> ») via l'API officielle Gmail : aucun port SMTP, aucun domaine à vérifier. 500 e-mails/jour max. Si une clé Resend est renseignée, celle-ci passe en priorité.
Vérification…
Compte indépendant de la connexion Drive (qui sert au tri des albums sur le Drive de votre compte photo) : ici, vous connectez le compte dont partiront les e-mails, par exemple votre Gmail pro.
Clé de secours — à coller dans la variable GOOGLE_MAIL_REFRESH_TOKEN de votre hébergeur pour pouvoir restaurer après un redéploiement :
⚠️ Bloc « SMTP classique » — les ports 25/465/587 sont bloqués sur le plan gratuit de Render : ce bloc ne fonctionne que si le serveur est en payant ou en local. Avec une clé Resend active, il est ignoré.
Laissez décoché pour STARTTLS (port 587, le plus courant).
Avec Resend : l'adresse doit appartenir à un domaine vérifié sur votre compte Resend (ex. « Mews Studio <galeries@mewstudio.com> »). Le nom d'affichage est libre.
